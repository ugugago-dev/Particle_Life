# 有機的な描画 仕様書

粒子を「点の集まり」ではなく「細胞・SmoothLife の構造」のように見せる描画 (`renderMode: 'organic'`)。
シミュレーション側は変更しない (描画は位置・種類の読み取りだけ)。`renderMode: 'dots'` は従来どおりの点描画で、変更なし。

参考にしたもの:

- 水彩の生物細胞イラスト (青 -> ミント -> 淡黄の体、紫の核、顆粒) = cell
- 明視野の光学顕微鏡の写真 (オオカナダモの葉の細胞 = 淡い背景に半透明の細胞室と暗い縁の丸い葉緑体、TEM = 縁のくっきりした暗い丸い顆粒と細かい粒状) = scope

## パイプライン (organic のとき、トレイルは無視して不透明な全画面を描く)

| # | パス | 入力 -> 出力 | 内容 |
|---|---|---|---|
| 0 | paper (cell / scope だけ) | -> `paper` (rgba8unorm, canvas 解像度) | 画面固定のノイズ (紙の目・体の縁の揺らぎ・核の縁の揺らぎ。scope では粒状ノイズ・縁の揺らぎ・染色のむら) を焼く。canvas のサイズ / dpr が変わったとき (plan を作り直したとき) だけ |
| 1 | splat | 粒子 -> `field` (rgba16float、周囲に余白) (+ cell だけ `granule` (r16float、余白付き)) | 粒子ごとの四角形 (4 頂点の triangle-strip、instance = 粒子) を加算。`field` = (色 x w, w) (scope だけ `(w cosθ_t, w sinθ_t, 0, w)` = 種類の角度。下記 scope)。カーネルは等方の `(1 - d^2)^3`。周期境界のコピーは描かず、端をまたぐ分は余白 (スプラット半径 + 1 px) に落とす。cell は MRT のパイプライン (`fsGranule`)、ほかは field だけのパイプライン (`fs`) |
| 2 | shape | `field` -> `shaped` (L0) (+ cell だけ顆粒 -> 余白なしの `granule`) | 余白に落ちた端のはみ出しを反対側の端へ折り返して足し (周期境界)、スタイルに合わせて場を整形 (後述)。出力は `(平均色 x c, c)` (scope は `(e x c, d, c)`、d = 圧縮した同種の密度)。cell は顆粒も、`softLarge` のスタイル (scope) は large 用の柔らかい整形 `shaped large` も同じパスで書く (MRT、`fsGranule` / `fsSoft`)。scope の `fsSoft` は前フレームの large ぼかしも読む (異種の分離、下記) |
| 3 | downsample | L(k-1) -> L(k) | 2x2 の箱平均で 1/2 ずつ縮小。ブラーの σ が大きいときだけ (下記)。`softLarge` は `shaped large` からも large 用の縮小列を作る |
| 4 | blur x 4 | L(ks) -> small、L(kl) -> large (`softLarge` は `shaped large` の列から) | 分離ガウス (水平 -> 垂直) を small (disk) と large (ring) の 2 本。サンプラは repeat (周期境界)。表の `params` に `blurLarge` が無いスタイル (現在は無い) は large のブラーと、その分の縮小段を作らない |
| 5 | composite | small + large + granule -> canvas | スタイルの着色。不透明。そのあとに粒子の重ね描き (`showParticles`) とポインタ円 |

解像度:

- `field` / `shaped` / `granule` は canvas x `fieldScale` (既定 0.5)。リサイズ・DPR 変更・スタイル変更 (large / 顆粒を使うかが変わるとき) は、field サイズと縮小段数・使うものの数値を毎フレーム前回の計画と比べて、変わったときだけテクスチャ・バインドグループを作り直す。顆粒テクスチャは cell だけ確保する。
- ブラーは 1 方向の σ を 5 テクセル以下に収める: σ (field の px) が大きいときは `ceil(log2(σ / 5))` 段だけ 1/2 に縮小した解像度で行う (最大 1/64)。small と large は別々に段数を決める。
- タップは「2 テクセルを 1 フェッチにまとめたバイリニア」の表 (CPU で計算して uniform に入れる。σ が変わったパスだけ書き直す)。半径 3σ (σ ≦ 5 テクセルなら 15 テクセル) で 1 方向 17 フェッチ、上限は 33 フェッチ。
- composite は small をバイリニアで canvas 解像度に引き伸ばしてサンプルし、large / granule は使うスタイルの分岐の中でだけサンプルする (使わないスタイルでは small が束縛されているだけ)。

## 正規化 (粒子数・画面サイズ・rMax に依存しない)

`field` は **画面全体の平均密度のとき 1**。粒子 1 個の重みは `w = 1 / (1.5 * ρ_mean * splatRadius^2)`。

- 密度 ρ = 重み付き近傍数 `Σ(1 - r/rMax)^2` の一様な場の粒子数密度は `n = 6ρ / (π rMax^2)`、カーネルの面積は `π s^2 / 4` (`s = splatRadius * rMax`)。よって `field = w * n * π s^2 / 4 = 1.5 * w * ρ * splatRadius^2`。
- 平均密度 `ρ_mean = N π rMax^2 / (6 A)` (A = 世界の面積 = アスペクト比 x 1)。
- 圧縮の制限が弱いと構造の芯は平均の 5〜30 倍になる (下の「実測した密度」)。なので `restDensity` は基準にしない。芯の高さは `fieldGain` と shape の飽和曲線で受ける。
- ブラー半径・スプラット半径は `rMax` の倍率 (ワールド単位) で持ち、field の px へは `fh / world.height` で換算するので、画面サイズ・DPR に依存しない。

## 実測した密度 (しきい値の根拠)

既定の設定 (60,000 粒子、rMax 0.03、restDensity 20、pressureStrength 0.005、16:9) で、ランダムなルール 4 通りを 1500 ステップ (15 秒) 回して測った
(field は 960x540 = fieldScale 0.5 の 1920x1080 相当。ρ_mean ≈ 15.9)。

- 粒子ごとの密度 ρ / ρ_mean は**二峰性**: ガスの山 ~0.35〜0.5 倍 (5〜8 個の小さな粒の塊。dots で散らばって見える点)、構造の山 4〜11 倍、谷は ~1〜1.4 倍。
  圧縮の制限は弱く (restDensity 20 ≈ 1.26 倍を超えても押し返しが小さい)、芯は 10〜30 倍まで詰まる。
- 粒子の位置での field の値 (ガスの粒子 = ρ < 1 倍、構造の粒子 = ρ > 1.5 倍):

| スプラット (x rMax) | 使うスタイル | ガス 中央値 / 90% / 99% | 構造 1% / 10% / 中央値 | 二つを分ける最適なしきい値 (誤分類) |
|---|---|---|---|---|
| 0.5 | cell | 0.6〜0.9 / 1.1〜1.5 / 1.6〜2.0 | 1.6〜2.3 / 2.9〜4.3 / 6.7〜12.6 | 1.8〜2.1 (0.4〜1.7%) |
| 0.3 | (旧 bands。測定のみ) | 0.8〜1.4 / 1.5〜2.5 / 2.4〜3.6 | 1.6〜2.6 / 3.5〜5.1 / 8〜15 | 2.6〜3.3 (1.4〜5%) |
| 0.15 | glass | 1.7〜2.4 / 2.9〜4.3 / 4.5〜6.6 | 2.1〜3.3 / 4.5〜7.2 / 10〜19 | 4.1〜5.1 (2.4〜8.7%) |

scope のスプラットは 0.2 (= 0.4 x 0.5)。粒 (ごみ) 対策のために、次の節で粒の塊ごとに測り直した。

- 画面の面積の 50〜70% は field < 0.3 (粒子の無い所)。ガスは一様な薄い場ではなく、小さな塊が点々と並んだもの。
  以前の `threshold 0.6` はガスの塊をほぼすべて通していた (cell が点だらけ、核が肥大)。
- この測定から: `threshold` 1.5 (ガスの粒子の ~90% を落とし、構造の縁の細い膜 (粒の鎖の弧) は一部残す。2.0 だと膜も消える)、
  glass の `coreThreshold` 0.8 (圧縮後。field ~4.6 = 細かい場でのガスの 90〜99% 点)、cell の `nucleusThreshold` 0.7。

### scope: 粒の塊の密度 (ごみ対策の測定)

乱数ルール 6 種 (seed 5、60,000 粒子、16:9、1250 ステップ) で、粒を距離 0.006 (= スプラット半径 0.2 rMax) でつないだ塊に分け、塊の大きさ別に field の値 v (scope のスプラット 0.2、`fieldGain` 1) と large ぼかし n を GPU から読み戻して測った。

| 塊の粒数 | 塊の数 | v のピーク p10 / p50 / p90 / max |
|---|---|---|
| 1 | 2940 | 0.92 / 0.98 / 1.04 / 4.5 |
| 2〜3 | 969 | 1.03 / 1.30 / 1.81 / 2.7 |
| 4〜6 | 356 | 1.37 / 1.77 / 2.49 / 3.4 |
| 7〜12 | 221 | 1.65 / 2.33 / 3.35 / 6.1 |
| 13〜30 | 144 | 2.04 / 3.00 / 4.62 / 9.5 |
| 31〜100 | 156 | 3.22 / 4.75 / 10.3 / 17.3 |
| 101〜300 | 66 | 4.78 / 7.99 / 14.1 / 21.6 |
| 301〜 | 24 | 7.78 / 26.7 / 40.2 / 42.4 |

- 粒 1 個のピークは `weightNorm` そのもの (1 / (1.5 ρ_mean s^2) = 1.05)。しきい値 (実効 2 以上) より遥かに下で、単独の粒は描かれない。目に付く「点」は 7〜100 粒の小さな塊 (ピーク 2〜10)。
- 大きな細胞 (101 粒〜) の粒の位置の v は p10 2.3 / p50 4.9 / p90 10.6。殻 (縁の弧・鎖) の粒は v 2〜5 で、小さな塊のピークと**同じ範囲**。v だけではごみと殻を分けられない (しきい値を上げると同じだけ両方が消える)。分けられるのは周りの質量 (n)。
- n (large ぼかし、旧 shape の実効しきい値 3.9) のピーク p50 / p90: 1〜30 粒の塊 0.00〜0.01 / 0.03〜0.06、31〜100 粒 0.02 / 0.41、101〜300 粒 0.17 / 0.36、301〜 0.58 / 0.87。ごみには周りの質量が無い (n ≈ 0)。

しきい値が n (= 体の輪郭・殻) に伝わる経路 (コードで確認): `shapeField` の `c = 1 - exp(-2 * max(v - threshold, 0))` が `shaped` に入り、small も large も同じ `shaped` (L0) から縮小・ぼかしを作る。`threshold` を上げると v がしきい値の近くの画素 (殻・疎な縁) の `c` が下がり、large ぼかしの n が下がって `n = 0.2` の等高線が内側へ寄る。同じ状態で測ると、実効しきい値 1.5 / 3.0 / 3.9 / 4.8 / 6.0 で、大きな細胞の粒のうち壁の外に出る割合が 2.9 / 20 / 28 / 34 / 37%、`n > 0.2` の面積が 17070 / 6402 / 4602 / 3663 / 3068 テクセル。しきい値を上げるとごみと同時に殻が痩せる。

試したこと (すべて同じ粒の状態で比較):

- A (殻をしきい値から切り離す): large 用に別の整形 `1 - exp(-(v / s)^p)` (しきい値に依存しない) を作り、large ぼかしだけそちらから作る。`s` が小さい (2〜4) と疎なガスの筋が薄い「幽霊の細胞」(壁付き) になる。`s = 6, p = 2` で旧しきい値 3.9 の体と同じ大きさ、`s = 5` で少し大きい。殻は安定するが、A だけでは小器官 (small) のごみは減らない。
- B (文脈で隠す): 小器官を `n` で隠す。small と large が同じ `shaped` のままだと、しきい値を下げて殻を戻すと n の輪郭も広がり、ガスの筋が壁付きの細胞になる (比較: A + B のほうが壁の数が少ない)。B だけでもごみは消えるが、殻の大きさがしきい値に連動したまま。
- C (小器官の応答を非線形に): `c = 1 - exp(-0.43 (v / T)^p)` (v = T で 0.35、p = 2.5 / 4)。単独の粒 (v ≈ 1) はもともと見えず、7 粒以上の塊は線形のしきい値と同じ範囲に入るので、ごみは減らなかった (同じ T で見える塊の数が 39 / 50 / 127 -> 48 / 65 / 129)。採用しない。
- 採用: A + B。small = 低めのしきい値 (実効 2.4: 殻の弧・小さな器官が戻る)、large = しきい値に依存しない整形 (`s = 5, p = 2`)、小器官は体の中だけ描く (`scopeSpeck`)。同じ状態の前後 (実効しきい値 3.9 の旧版 -> 新版): 体の面積 4875 -> 6086 テクセル (新版は threshold 1.6〜3.2 で完全に同じ)、壁の外の粒 28% -> 21%、100 粒以下の塊のうち小器官が描かれる数 73 -> 25。描画時間 (NVIDIA、HUD) 0.56 -> 0.58 ms。

## スタイル表 (`src/organicStyles.js`)

スタイルごとの違いは 1 つの表 `ORGANIC_STYLES` にまとめてあり、レンダラ・WGSL・GUI はここから導く。

| 項目 | 意味 |
|---|---|
| `index` | WGSL の `STYLE_<NAME>` (表から生成した定数。composite の `switch` の case) |
| `fine` | スプラット半径 / small ぼかし / large ぼかしの倍率 (glass: 0.3 / 0.3 / 1、scope: 0.4 / 0.4 / 1、cell は 1) |
| `shape` | shape パスの種類 (`occupancy` / `nucleus`)。WGSL の `SHAPE_<NAME>` |
| `granules` | 顆粒テクスチャを使う (cell だけ) |
| `paper` | 画面固定のノイズのテクスチャを焼く (cell / scope) |
| `params` | そのスタイルが読むスタイル固有の config 項目。GUI はこれに含まれる項目だけ表示する。`blurLarge` を含まないスタイルは large ぼかしを作らない |
| `thresholdScale` | `threshold` に掛ける倍率 (省略 = 1)。scope だけ 1.6 (細かい場ほど粒ごとの密度が高く出るため) |
| `softLarge` | large ぼかしを `shape` ではなく、`threshold` に依存しない柔らかい整形 (下記 soft) から作る (scope だけ)。`granules` とは併用しない |

## shape (ぼかす前の整形)

`v = field.a * fieldGain` (平均密度 = 1) として、スタイルの `shape` ごとに:

- occupancy (cell / scope): `c = 1 - exp(-2 * max(v - threshold, 0))` (scope の `threshold` は `thresholdScale` 倍)。空き (ガス) は 0、構造の内部は ~1 の「占有度」。SmoothLife の場の値 (0 か 1 に近い) に当たる。これを small / large でぼかしたものが disk 平均 m、ring 平均 n (scope の n は下の soft)。
- soft (scope の large だけ。`softLarge`): `c = 1 - exp(-(v / 5)^2)`。`threshold` に依存しない。疎なガス (v ≦ 2) は c ≦ 0.15、密な所 (v ≧ 10) は 0.98 以上に飽和。出力は `shaped large` へ `(平均色 x c, c)`。
- nucleus (glass): 圧縮 `c0 = 1 - exp(-(v / 3.5)^1.8)` のあと `c = smoothstep(coreThreshold - 0.1, coreThreshold + 0.1, c0)`。「核 (密度が高い所) の指標」で、ガスも疎な粒の殻も 0。体・核・膜はすべてこの指標のぼかしから作る。

出力は `(field.rgb / field.a * c, c)`。ぼかし後の `rgb / a` が加重平均色 (種類の色)。scope だけは `(e * c, d, c)` (`e = field.rg / field.a` = 種類の角度の平均ベクトル)。b の `d = 1 - exp(-v_coh / 12)` (`SCOPE_DENS_S` = 12、P = 1) は small 用の occupancy の出力だけに入る圧縮した**同種の**密度で、`c` を掛けない (占有度 `m` は ~1.5 で飽和するが、d は塊の大きさとともに増え続ける: 1 種類の塊で殻 v 2〜5 -> 0.15〜0.34、大細胞 v 10 -> 0.56、300 粒以上の塊 v 30 -> 0.92)。`v_coh = |field.rg| * fieldGain` (種類の角度のベクトルの和の長さ) は 1 種類だけの所では `v` と同じで、種類が混ざる所では小さくなる (隣の種類の等量混合で `cos(π/N)` 倍、対蹠の 2 種類の等量混合で 0)。種類ごとの密度そのものではないが、追加のパスなしで「別の種類の粒子を数えない」密度になる。ぼかしは線形なので、composite は `ρ = s.b` (ぼかし後の d) をそのまま読む。soft (large) の b は**体の場** (`c_soft` から純粋な細胞の周りの異種の分を除いたもの。`scopeIsolation` = 0 なら `c_soft` と同じ値)。rg / a は減衰しない (種類の判定と細胞質の色に使う)。

## スタイル (`organicStyle`)

以下 `m` = small ぼかし後の `a`、`n` = large ぼかし後の `a`、`C` = `rgb / a` (種類の平均色)。`tinted(base, C, k)` は明るさを保って色相を C へ `k` だけ寄せる。

### glass

平らな 2D イラスト風の細胞 (3D 的なライティングはしない)。背景は青、体は一定の淡い水色の半透明、縁は白い線、核は種類の色の平らな塊。
**色の意味は核だけ** (体・膜には種類の色を混ぜない)。`m` / `n` = 核の指標 (shape) の small / large ぼかし、`Cs = s.rgb / s.a` = small ぼかしの加重平均色 (細かい)。
輪郭はすべて `fwidth` による約 1px のアンチエイリアスで、ぼかしの強さによらず「くっきりだが少し柔らかい」平面の形になる。

- 背景: 平らな青 `(.27,.57,.88)` -> `(.20,.47,.82)` のごくゆるい上下グラデーションだけ。
- 体: `n > 0.2` の半透明の円盤 (一定の `(.62,.82,.98)`、背景に 80% で重ねる)。核の指標から作るので、核を持たないガスのかたまり・疎な粒の殻は体にならず、輪も出ない。
- 膜: 体の輪郭の等高線 `n = 0.2` に沿った一定幅 (canvas px、半幅 `0.9 * rimStrength * dpr`) の白い線。勾配が弱い所 (平らな頂上・くびれ) では出さない。
- 核: `m > 0.5` の内側を `Cs` で平らに塗る。細かい場 (スプラット 0.3 倍 x 0.5 = 0.15 rMax、small ぼかし 0.3 倍) の色なので、粒が作る縞 (緑 / 赤) や色の混ざりがそのまま残る。
  縁に、自分の色を暗く (x 0.62) 少し濃くした約 1px (`1.2 * dpr`) の縁取りを付けて、淡い体から分離する。`n < 0.2` の小さな粒は核としても出さない。
- 画面固定のノイズ・スペキュラ・陰影・屈折・ビネット・外側の輪は使わない (動いても揺らがない)。
- glass は細かい場 (スプラット 0.3 倍、small ぼかし 0.3 倍)。large ぼかしは縮めない (体の輪郭に使うため)。

### scope (既定)

明視野の光学顕微鏡の像。淡い透過光の背景、細い壁で囲まれた半透明の細胞、染色された丸い小器官。**種類 (色) が一目で区別できること**が必須条件。
`s` = small ぼかし (`m = s.a`、shape = occupancy。`threshold` が効く)、`l` = large ぼかし (`n = l.a`、softLarge の soft 整形。`threshold` に依存しない)。色はぼかした色の平均ではなく、種類を復元してパレットの正確な染色で塗る (`docs/scope-species-spec.md` のフェーズ 1):

- 種類の埋め込み: splat は種類 t を角度 `θ_t = 2π (t + 0.5) / N` (`N` = `OrganicParams.numTypes`、パレットの種類数、最大 16) の単位ベクトルにして足す。ぼかし後の `e = rg / a` (`es` = small、`el` = large) の向きが種類、`|e|` が純度 (1 = 1 種類、隣の種類との等量混合で `cos(π/N)`)。
- 復元 (`decodeSpecies`): `u = atan2(e) / (2π/N) - 0.5`、`i0 = floor(u) mod N`、`i1 = i0 + 1` (e を挟む 2 つの種類)。2 つの境界 (角度 `(floor(u) + 1) 2π/N` の半直線) までの e 空間の符号付き距離 `side = dot(e, (-sin φ, cos φ))` (i1 側が正)。atan2 の折り返し・N = 2 や対蹠の種類 (e が原点を通る) でも連続。
- 小器官の色: `T = mix(transmit[i0], transmit[i1], saturate(side / (|dpdx es| + |dpdy es|) + 0.5))` = 約 1 px で AA した硬い切り替え (第三の色相は出ない)。切り替えの位置に細い暗線 (半幅 `0.4 dpr`、不透明度 0.5、色 = 両側の輪郭の色の平均 x 0.5)。N = 1 (i0 = i1) では出さない。
- 混合域の判定 (`keep`): 離れた種類の混合は角度が間の別の種類を指す (例: 6 種類で紫 + 黄 -> 緑)。純度 `|e|` を `cos(2π/N)` (2 つ離れた種類の等量混合) -> 0、`cos(π/N)` (隣の種類の等量混合) -> 1 に正規化し、正規化値 0.3 -> 0.55 の範囲 (ただし R の値で 0.55 / 0.75 を上限にする) の smoothstep を `keep` とする。`keep = 1` の画素は上の復元そのまま (従来どおり。タップも読まない)。偽の種類が出る範囲は正規化値 0.21 (N = 6) / 0.30 (N = 10) / 0.32 (N = 16) 以下 (R で 0.58 / 0.85 / 0.94 以下)。上限 (R 0.55 / 0.75) は種類が多いとき用 (正規化だけだと N = 10 / 16 では小器官の大半が混合域になる)。そのため、隣同士の色が近い N ≧ 10 では、2〜3 つ離れた種類の混合 (N = 10 の 2 つ離れた組、N = 16 の 3 つまで離れた組) は `keep = 1` のまま上の復元で間の (色相も間の) 種類として出る (下の両側の処理は効かない)。N ≦ 3 では全ての組が隣同士なので、`keep < 1` は 3 種類がほぼ等量のときだけ (N = 2 / 3 の画は変わらない)。
- 混合域は両側の純粋な小器官で塗る (`pureSides`、`docs/scope-species-spec.md` の実装メモ (混合域の両側))。混合した e そのものは復元しない (偽の中間の種類が出ない)。`keep < 1` かつ `m > 0.2` の画素だけ (一様でない分岐なので中で微分は使わない):
  - small ぼかしを 8 方向 x 2 距離 (`mixPx` x 1, 2、`mixPx = sqrt((0.3 r_splat)^2 + σ_small^2)` = スプラットの核と small ぼかしを合わせた混合の幅、field px。`σ_small` は OrganicParams の `sigmaSmall`) で読み、タップごとに得点 `score = keep_k * smoothstep(0.2, 0.35, m_k)` (純粋な小器官に当たったか) と復元 `i0 / i1 / side` を求める。得点は `i0` / `i1` に `w = saturate(side / sin(π/N) + 0.5)` で連続に分け、種類ごとの最高点 `best[]` と合計 `sum[]` を取る (自分の画素も `keep` の分だけ候補)。
  - 色: 候補 (best > 0) のうち `aff = dot(es, 種類の向き) - 1.0 (1 - best)` の上位 2 つを A / B とし、`T = mix(T_A, T_B, saturate(dAB + 0.5))`、`dAB = (aff_B - aff_A) / |e_B - e_A| / (|dpdx es| + |dpdy es|)` (罰則が無ければ e 空間で A と B の垂直二等分線 (原点を通る) までの px 距離。隣の種類なら上の `side` と同じ)。区切り線も `dAB` で同じ幅に引く。自分の復元へは `smoothstep(0.75, 1, keep)` で戻す (keep の途中で自分の復元を混ぜると、隣の偽の種類の色と区切り線が淡く出た)。
  - 不透明度: `cover` に `mix(SCOPE_MIX_COVER = 0, 1, keepEff)` を掛ける (染色・レリーフ・スペキュラ・輪郭・外側の明るい線・区切り線すべて)。`keepEff = max(keep, smoothstep(0.15, 0.35, cov) * smoothstep(0.6, 0.95, share))`、`cov` = タップの得点の平均 (周りが純粋な小器官で占められている割合)、`share` = 得点の合計のうち上位 3 種類の割合 (3 つの小器官が接する所も含める。多種類が入り組んだガスの塊では低い)。接触帯は不透明に塗られ、純粋な側の無い多種類の混ざりだけが従来どおり透ける。粒子の無い隙間は `m` の輪郭 (`cover = saturate(d + 0.5)`) が残す (同じ種類の隙間と同じ扱い。ぼかしより狭い隙間は埋まる)。
  - 旧版 (フェーズ 1〜3) は混合域全体の不透明度を `keep` で落としていたので、離れた種類が接する所 (6 種類の紫 (0) と黄 (4) など) に白い隙間が開き、ぼかしと同じ幅のフェードで細い小器官 (輪) が切れて見えた。
- 細胞質の色: `el` から同様に復元し、隣の種類と線形補間 (`saturate(side / sin(π/N) + 0.5)`、u の幅 0.5 の柔らかい切り替え)。こちらの安全弁は不透明度ではなく、透過率を淡い灰色 (`mix(luma(T), 1, 0.5)`) へ `1 - keep` だけ寄せる (ごく薄い色なので目立たない)。
- 種類ごとの染色 `stain[16]` / 透過率 `transmit[16]` (`min(stain / 背景, 1)`) は `src/stainColor.js` の `buildStainTables` でパレットが変わったときだけ計算し、composite が読む `transmit` だけを binding 7 (uniform `StainTables`、256 バイト) へ書く。背景色 `SCOPE_BG` も stainColor.js の値を WGSL へ埋め込む。

- 背景: 淡い暖色の透過光 `(.93,.94,.88)`。paper の `g` で ±2.5% の照明むら、`r` の粒状ノイズ (全体に ±8%)。接眼レンズのビネット = 中心からの距離を対角線の半分で割った `r` (角で 1、アスペクトを保った円) で `1 - 0.55 * scopeVignette * smoothstep(0.4, 1, r)` を全体に掛ける (0.6 で角は 0.67 倍。最大でも 0.45 倍で、真っ黒にはならない)。
- 体 (細胞質): `n` (soft 整形の large ぼかしの体の場 `l.b`。+ 低周波ノイズ ±0.04) の等高線 `n = 0.2` の内側に、`el` から復元した種類の染色の透過率を `0.1 * scopeStain` 乗した、ごく薄い色を掛ける。壁 = 輪郭に沿った暗い灰色の線 (半幅 `0.7 dpr`、不透明度 0.65) と、その外側 `1.6 dpr` の明るい線 (屈折のハロー、不透明度 0.7)。どちらも `fwidth` の px 距離で AA し、勾配が弱い所 (`fwidth(n)` が 0.002〜0.005 未満) では出さない (glass の膜と同じ)。
- 小器官: `m = 0.35` の等高線の内側を Beer-Lambert の吸収で染める。`col = 下の色 * pow(T, k * m * 厚み * 粒 * min(dens, 1))` (dens は下の密度。`scopeDensity` = 0 (既定) なら 1) (T = 上記の復元した種類の透過率)。体の外の小さな塊は描かない (`scopeSpeck`): 減衰しない `l.a` (+ 同じノイズ) が `0.2 * scopeSpeck` 未満の所は隠す (`aaStep`、輪郭は `fwidth` で 1 px の AA。半透明にすると薄いしみが残るので、0 か 1 の切り替え)。`scopeSpeck` = 1 で体の輪郭 (n = 0.2) の外は描かず、0.5 で輪郭のすぐ外 (n ≧ 0.1) まで、0 で隠さない。
  - `T = transmit[種類]` (密度 1 の染色の色を背景で割った透過率)、`k = scopeStain / 1.5` (既定で密度 1 の所がちょうど `stainColor`)。`scopeDensity` > 0 なら薄い縁は淡く、濃い芯は深い (密度で濃くする分は下の密度の項。色相を保つ)。
  - `厚み = mix(0.7, 1, smoothstep(0.15, 0.85, n))` (大きな塊ほど厚く、中心が濃い)。`粒 = 1 + 1.2 (r - 0.5) + (b - 0.5)` (paper の細かい粒と低周波のむらによる染色ムラ。画面固定なので粒子が動いても揺らがない)。
  - 輪郭: 縁の内側 `1.3 dpr` に自分の色を暗くした線 (`下の色 * T^(2.2 k) * 0.6`)、外側 `1.5 dpr` に明るい線 (不透明度 0.4)。`fwidth(m)` による AA。
  - 斜光のレリーフ (DIC 風): small の `a` の勾配 (±1 テクセルの中央差分) を高さとみなし、固定光源 (左上) の陰影 (振幅 ±0.18) と、光源側に寄せた半ベクトルでの小さなスペキュラ (`pow(.., 48) * 0.15`)。
  - 密度 (`docs/scope-species-spec.md` のフェーズ 2、強さは `scopeDensity`、**既定 0 = 使わない**): `ρ = s.b` (同種の密度)、`dens = mix(1, 0.6 + 1.4 ρ, scopeDensity)` (`SCOPE_DENS_BASE` / `GAIN`)。`scopeDensity` = 0 で dens = 1・`deep` = `core` = 0 となり、小器官の染色・輪郭の線は密度に依存しない (フェーズ 1 の式。旧核小体は戻さない)。実機で「核ではなく縁取り (縁が淡く内側が濃い) に見える」との報告があり既定を切った。染色の指数に `min(dens, 1)` を掛ける (ρ < 0.29 の薄い所 = 縁・殻 (小さな塊は縁だけ) は従来より淡く、それ以上は従来どおり)。1 を超えた分と核の帯は色ごとの指数ではなく、透過率の輝度 `lt = luma(T)` のスカラーの累乗で暗くする (`pow(T, x)` は x > 1 で色相が動く: 橙 (OKLab h58) は x = 1.5 で h44、2 で h37 と赤へ寄る。スカラー倍なら OKLab の色相は変わらない): `big = smoothstep(0.3, 0.5, n)` (大きな細胞だけ。小さな密な塊は ρ が 0.45〜0.6 に達するので除く)、`core = scopeDensity * smoothstep(0.55, 0.8, ρ) * big` (核の帯)、`deep = 0.35 * max(dens - 1, 0) * big`、`小器官 *= lt^(k * (deep + 0.6 core))`。核では彩度を `mix(luma, 色, 1 + 0.1 core)` だけ上げる (0.1 を超えると橙が赤へ寄る)。既定のシーンの核 (ρ ~0.8) で OKLab の L が 25〜33% 下がり、色相の中央値はパレットの色相 ±3° のまま (生の密度で測った値。同種の密度にしてからは、別の種類の小器官と接する縁の ρ が下がり、暗い帯は 1 種類の大きな塊の内側だけに残る)。
  - 輪郭の線の色にも `lt^(k * deep)` を掛ける (濃い所ほど濃い)。
  - (旧) 核小体 `n >= 0.85` で 20% 暗くする処理は、上の核の帯に置き換えて廃止した。
- 異種の分離 (`scopeIsolation`、`docs/scope-species-spec.md` のフェーズ 3): 純粋な細胞の近くの別の種類の粒子が壁を押し出さないようにする。
  - shape (`fsSoft`) は**前フレームの large ぼかし** `l` を binding 3 (サンプラ binding 4 = field と同じ repeat) で読む。このフレームの large ぼかしは shape のあとのパスで書かれるので、同じパスで読み書きしない。plan を作り直した直後は 0 (= 減衰なし)。
  - `l` の主な種類 `D = round(u_l)` と純度 `pure = smoothstep(0.55, 0.85, |e_l|) * (1 - smoothstep(0.1, 0.25, |u_l - D|))` (`dominantSpecies`。2 つ目の項は |e| では見分けられない隣の種類との混合用)。テクセルの種類 `u_p` (自分の field の rg / a) が D から離れている分 `foreign = pure * saturate(circDist(u_p, D))`。
  - D に囲まれたテクセル (細胞の中の異種の核) は除かない: 8 方向 x 3 距離 (スプラット半径の 1〜3 倍の px) の生の field を見て、D 方向に射影した値 (`dot(f.rg, e_D)`、平均密度 = 1) が 1.5 以上の方向の割合 h から `foreign *= 1 - smoothstep(0.65, 0.9, h)`。
  - `b = c_soft * (1 - scopeIsolation * foreign)`。rg / a は減衰しない。D と純度を減衰した場から求めると、除いた分だけ純度が上がってさらに除く正のフィードバックになり、混ざった生物が削られる (実測で核のある小さな細胞が縮んだ)。減衰しない場から求めるのでフィードバックは無く、止めた状態では 1 フレーム目から同じ画になる。
  - composite: 壁・細胞質の範囲・`厚み`・`big` は `l.b`、細胞質の色と D は `l.rg / l.a`。小器官のゲートは `max(nGate, foreignS * aaStep(ρ, 0.35))` (`nGate` は上の `l.a` のゲート、`foreignS = pure(l) * smoothstep(0.03, 0.08, l.b) * saturate(circDist(u_s, D))`、`scopeIsolation > 0` のときだけ)。壁の外の異種の密な塊は自分の輪郭を持つ点として描かれる。 この ρ のゲートは `scopeDensity` によらず効く (ρ は同種の密度なので、異種の塊そのものの密度で判定される)。
  - large のぼかし (σ 0.45 rMax) は小さな細胞と同じくらいの大きさなので、効くのは細胞の周りの質量の数 % の小さな侵入 (既定のシーンで細胞の縁の数粒が壁を膨らませていた所) まで。30 粒の塊のように周りの質量の 2〜3 割になると純度が下がり、何もしない (純度のしきい値を下げると、境界ぎりぎりの細胞の壁が小器官を横切るなどの副作用が出た)。
- `stainColor` (種類を見分ける色、`src/stainColor.js`。CPU で計算): パレットの色を OKLab にして、色相 (a, b の向き) を保ったまま彩度 x1.2 (上限 0.19)、L を 0.15 下げる (L > 0.74 の黄は下げ幅を最大 75% 減らす。暗い黄は黄に見えない)。sRGB の範囲外は、線形 RGB で同じ L の灰色へ寄せて収める (色相が保たれる)。
  - 色の累乗ではなく `背景 * (色 / 背景)^密度` で濃淡をつける (色相がずれにくい)。単純に色を累乗すると橙が赤へ寄って赤と区別できなくなる (6 種類の橙 / 赤の OKLab 色差 ΔE x100 が 3 まで下がった)。
  - 密度 1 での種類間の最小 ΔE x100 (計算値、カッコ内はパレットそのままの値): 3 種類 29 (25)、6 種類 14 (11)、10 種類 5 (7)。10 種類では橙と琥珀 (隣り合う暖色) が近いが、これはパレットの色相の間隔 (23°) によるもので、パレットは変えていない。
- 細かい場: スプラット 0.4 倍 (実効 0.2 rMax)、small ぼかし 0.4 倍 (glass より粗く、cell より細かい。粒がくっきり出る)。large ぼかしは縮めない (体の輪郭用)。`threshold` は small の小器官だけに効き、`thresholdScale` (1.6) 倍の実効 2.4 が既定 (殻の弧・小さな器官が出る。ごみは `scopeSpeck` が隠すので高くしなくてよい)。体の輪郭・細胞質は `threshold` を動かしても変わらない。
- GUI に出す項目: `threshold` / `blurLarge` / `scopeStain` / `scopeVignette` / `scopeSpeck` / `scopeIsolation` / `scopeDensity` (+ 共通の `blurSmall` など)。`speciesTint` は使わない (種類の色は染色に直接入る)。

### cell

水彩の細胞イラスト。背景はオフホワイトの紙 (画面固定の value noise で目を付ける)。

- 画面固定のノイズ (紙の目 = `0.6 vnoise(px 0.8) + 0.4 vnoise(px 2.3)`、縁の揺らぎ = `fbm(px 0.045)`、核の揺らぎ = `fbm(px 0.11)`、px = CSS px) は
  paper パスで rgba8unorm のテクスチャに焼いておき、composite は 1 回の `textureLoad` で読む (毎フレーム画素ごとに最大 32 回のハッシュを計算しない。8 bit への量子化による差は画面で最大 1/255)。
- 体: `mb = mix(m, n, 0.4) + 低周波ノイズ`、`body = smoothstep(0.3, 0.62, mb)` (縁 = 占有度 0.5 付近の等高線、ノイズでやや不規則)。外側に薄い青のにじみ。
- 色: 深さ `depth = smoothstep(0.45, 0.98, mix(m, n, 0.6))` (縁 0 -> 内部 1) で 青 `(.36,.56,.86)` -> ミント `(.72,.91,.82)` -> 淡黄 `(.99,.96,.72)`。縁に少し濃い帯 (顔料だまり)、紙の目でムラ。
- 核: `nuc = smoothstep(nucleusThreshold ± 0.03, n + 粗いノイズ)`。縁が濃く中心がやや明るい紫。大きなぼかしがほぼ満杯の所 = 大きな塊の中心だけに出る。
- 顆粒: splat のときに粒子の約 3% (id のハッシュ) が、向きがランダムな小さな楕円 (長軸 0.42 s、短軸 = 長軸 / 1.7) を `granule` へ加算。composite で体の内側だけ薄く暗く描く。粒子といっしょに動く。

| `scopeStain` | 1.5 | 0〜4 | scope: 染色の強さ (密度 1 の吸光度。1.5 で密度 1 がちょうど染色の色、大きいほど濃く暗い、小さいほど淡い) |
| `scopeVignette` | 0.6 | 0〜1 | scope: 接眼レンズのビネットの強さ (0 = 一様な照明) |
| `scopeSpeck` | 1 | 0〜1 | scope: 小器官に要る周りの体の濃さ (`n >= 0.2 * scopeSpeck`)。1 = 体の中だけ、0 = 体の外の小さな塊も描く |
| `scopeIsolation` | 0.85 | 0〜1 | scope: 純粋な細胞の周りの異種の粒子を体の場から除く割合 (壁を押し出さず、密な塊は壁の外の独立した点になる)。0 = 除かない (フェーズ 2 と同じ画) |
| `scopeDensity` | 0 | 0〜1 | scope: 同種の密度 ρ で染色の深さを変え、大きな細胞の芯を暗くする強さ (フェーズ 2 の効果全体に掛かる)。0 = 使わない (密度によらない染色)、1 = フェーズ 2 の式そのまま |
| `showParticles` | false | | 粒子 (半径半分、alpha 0.3) を上に重ねる |

以前の `edge` / `coreBoost` / `stretch` と、旧 `threshold` (メタボールのしきい値) は廃止。`threshold` は上記の意味に変わった。
しきい値の既定は「実測した密度」の節の測定から決めた。粒子数・rMax・圧縮の制限を大きく変えて密度の分布が変わったら、同じ手順で測り直す。

## 調整のコツ (目で見て決める所)

- 構造の大きさは rMax 基準 (実測: 1 つの塊の半径がおよそ 0.5〜1 rMax)。輪郭が太すぎる / 細すぎるときは `blurLarge` と `splatRadius` を同じ向きに動かす。
- cell の核は `blurLarge` が大きいほど出にくい (n が下がる)。`nucleusThreshold` を下げるか `blurLarge` を下げる。
- ガスが見えすぎる / 構造が痩せるときは `threshold` (1.2〜2.0 が実用範囲。2.0 でガスはほぼ消えるが細い膜も消える)。
- glass で小さな粒が白い縁の欠片として出るときは `coreThreshold` を上げる (0.85 以上では小さな本物の核も消え始める)。
- scope の背景に細かい粒 (ごみ) が見えるときは `scopeSpeck` を上げる (1 で体の外は描かない。小さな細胞の壁が出るのを避けたいときは `blurLarge` を上げる)。殻の弧・小さな器官が足りないときは `threshold` を下げる (体の輪郭は動かない。下げすぎると体の中が細かくなりすぎる)。
- scope の種類が見分けにくいときは `scopeStain` を上げる (深い色になる。上げすぎると暗く潰れる)。TEM のように暗い顆粒にしたいときは 3 前後。
- scope の細胞の壁・小器官の輪郭は `fwidth` の px 幅 (dpr 倍) なので、`blurLarge` / `blurSmall` を変えても線の太さは変わらない。

## パレット (`src/palette.js`)

種類の色は OKLCH で生成する (dots モードと行列エディタも同じパレット)。HSL の等間隔の色相 (赤・黄・緑・水色・青・マゼンタ) は、青が青い背景に溶け、水色が淡い体・白い縁と区別できず、明るさもばらばら (黄・水色は明るく青・マゼンタは暗い) だった。

- 明るさ L = 0.73、彩度 C = 0.16 を基本にそろえる。ただし黄は高い L でないと黄色に見えない (そろえると泥っぽいからし色になり、赤やピンクと平均したときも茶色くなる) ので、色相 96° を中心に raised-cosine の山 (半幅 60°) で L を最大 +0.16 (黄 ≈ 0.89)、C を +0.01 持ち上げる。橙は +0.06 ほど、赤・緑・紫・ピンクは基本の L のまま。sRGB に収まらない色は色相と L を保ったまま C を下げる。明るい体の上でも暗い dots の背景の上でも読める値。
- 色相は 295° (紫) -> マゼンタ -> 赤 -> 橙 -> 黄 -> 145° (緑) の弧に等間隔。背景の青 (OKLCH で L 0.57–0.65、C 0.14–0.15、h 251–256°) と体 (L 0.84、h 243°) の色相帯 (約 150°–290°) を避ける。6 種類なら 紫 / ピンク / 赤 / 橙 / 黄 / 緑。種類数はいくつでもよい (弧を等分する)。
- 7 種類以上では、隣り合う色の見分けのため L を交互に ±0.05 ずらす。
- `createPalette(n)` は従来どおり `{ numTypes, css, rgb }` を返す。css は `rgb(r g b)`。

## 実装メモ

- `src/organicStyles.js`: スタイル表 (上記)。
- `src/gpu/shaders/organic.wgsl.js`: `splatWGSL` / `shapeWGSL` / `downsampleWGSL` / `blurWGSL` / `compositeWGSL`。`paperWGSL` (cell / scope の画面固定ノイズ)。`OrganicParams` は 21 個の 4 バイト値 (84 バイト。style / shape だけ u32。fieldW / fieldH / margin は splat と shape の余白付き field の座標用、numTypes は scope の種類の角度用、sigmaSmall は scope の混合域の両側を探す距離用 (small ぼかしの σ、field px。`updateOrganicLayout` の値)、scopeDensity は config の値)。フィールド名は config.js の項目名と同じで、JS 側の `ORGANIC_FIELDS` と WGSL の struct の一致は起動時に `assertOrganicLayout` (common.wgsl.js の `assertStructLayout`) が確認する。`BlurParams` は 288 バイト。全画面三角形の頂点シェーダ `FULLSCREEN_VS` は render.wgsl.js のものを fade / blit / organic で共有する。
- `src/gpu/renderer.js`: `updateOrganicLayout` (field の解像度・σ・縮小段数)、`ensureOrganicPlan` / `buildOrganicPlan` (テクスチャ・パス・バインドグループ)、`drawOrganic`、`writeOrganicUniform` (変わったときだけアップロード)、`updatePalette` (パレットと scope の染色表)、`writeBlurUniforms`、`writeGaussianTaps`。
- `trails` は organic では無視 (dots に戻したときは従来どおり)。`densityA` は読まない (simulation.js の `needDensity` も無くした。density パスは圧縮の制限が有効なときだけ走る)。
- 性能の目安 (60,000 粒子、1920x1080、fieldScale 0.5、Intel UHD (内蔵 GPU)、描画 GPU 時間。下記の最適化の前の値): glass ≈ 4.3 ms、cell ≈ 11 ms (ノイズが重い)。dots は 0.5 ms。scope は NVIDIA (Ampere)・1600x900 の HUD の draw gpu で glass ≈ 0.30 ms、scope ≈ 0.58 ms (softLarge の MRT と large 用の縮小列で +0.02 ms。Intel UHD では未計測)。
- 最適化 (同じ見た目のまま仕事を減らしたもの。swiftshader 上のタイムスタンプで計測、絶対値は実 GPU と違う):
  - splat の周期境界を「粒子 x 4 instance」から「余白付き field + shape での折り返し」に: 頂点シェーダの実行が 1 粒子 24 回 -> 4 回 (strip 込み)。splat の時間 1/3。
  - cell の画面固定ノイズを焼く: composite の画素ごとのハッシュ計算 (最大 32 回) が textureLoad 1 回に。
  - 四角形 (dots / splat / ポインタ円) を triangle-list の 6 頂点から triangle-strip の 4 頂点に。
  - (画素単位で同じ画のまま仕事を減らしたもの。swiftshader では壁時計でもパスごとのタイムスタンプでも差が雑音に埋もれて測れなかった (scope の composite の中央値 253 -> 254 ms、同じ回の変えていない glass の composite が 211 -> 235 ms と揺れる) ので、減らした仕事の量だけ記す。実 GPU では未計測)
    - RenderParams も OrganicParams と同じく前回とビットで比べて変わったときだけ送る。organic の中間パスの `beginRenderPass` の記述は plan を作るときに作って使い回す (毎フレームの割り当てなし)。
    - scope の composite: 小器官の染色・レリーフ (small の 4 回のサンプル)・輪郭・区切り線は `cover > 0` の画素 (既定のシーンで画面の約 11%) だけ計算する (どれも `cover` 倍で混ぜるので外の画素では値が変わらない。微分は分岐の前で取る)。区切り線・輪郭の色 (pow) はさらにその線の上 (`sep > 0` / `ring > 0`) だけ、核・濃染の暗くする処理は `scopeDensity > 0` のときだけ。異種の塊のゲートは `scopeIsolation > 0` のときだけ、その atan2 は `decodeSpecies` のものを使う。`decodeSpecies` / `speciesSplit` の numTypes だけで決まる値 (cos 2 回・sin 1 回) は画素ごとに 1 回 (`SK`)。
    - `StainTables` は composite が読む `transmit` だけ (256 バイト)。
- 周期境界: splat の余白の折り返しとブラーの repeat サンプラで、画面の端でも輪郭が途切れない。縮小 (downsample) だけは端をクランプする (奇数サイズのときの最後の 1 テクセルだけ影響)。
  余白は field の大きさで頭打ち (スプラット半径が field より大きい極端な設定では 1 回分しか折り返さない。以前の 4 コピー方式と同じ)。

## 受け入れ基準

1. `renderMode = 'dots'` で従来と同一の見た目 (回帰なし)。
2. 各スタイルが参考の見た目 (上記) の方向になる: glass = 青い平らな背景に白い縁の半透明の細胞と、種類の色の平らな核 (中の縞・混ざりも dots と同じに読める)、cell = 青->ミント->淡黄の体 + 紫の核 + 顆粒、scope = 淡い背景 + ビネット + 粒状ノイズの上に、細い壁の半透明の細胞と、種類ごとに色相がはっきり違う染色された丸い小器官 (3 / 6 / 10 種類で区別できる)。
3. 粒子数・画面サイズ・rMax を変えても極端に暗く / 明るくならない (場は平均密度で正規化)。
4. ウィンドウリサイズ・DPR 変更・trails の ON/OFF・スタイル / 半径の変更で破綻しない。
5. WebGPU の validation エラーがコンソールに出ない。

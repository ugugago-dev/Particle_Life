# scope 描画の改善 仕様書 (種類の描き分け / 密度の色 / 異種の粒子の独立)

対象: `organicStyle: 'scope'` (PC = `src/gpu/shaders/organic.wgsl.js` + `src/gpu/renderer.js`、スマホ = `src/mobile/organicGl.js`)。
前提の仕組みは `docs/organic-rendering-spec.md`。glass / cell / dots の見た目は**変えない** (回帰なし)。シミュレーションも変えない。

## 動機 (現状の問題)

1. 種類の違う 2 粒子が「ぼかして混ざった」色で描かれる。dots では描き分けられているのに scope では無い。
   原因: splat が `色 x w` を種類をまたいで足し (`organic.wgsl.js` の splat `fs`)、小器官の色が `meanColor(s)`、細胞質の色が `meanColor(l)` = 線形平均なので、境界に第三の色相が出る。
2. 細胞に別の色の粒子が近づくと、外側に粒子が写り込み、細胞の輪郭も歪む。
   原因: 体の輪郭 (`n` の等高線) と小器官のゲート (`n >= 0.2 * scopeSpeck`) が種類を区別しない密度から作られ、異種の質量も壁を押し出し、ハローの内側なら何でも描かれる。細胞質の色も異種の色が混ざる。
3. 密度で色が変わらない。染色の濃さは占有度 `m` (しきい値 + ~1.5 で飽和) で決まり、生の密度が composite に届かない。

## 方針 (決定事項)

- ① 種類の復元 (案 A): scope の field には色の代わりに**種類を円周上の角度で表した 2 成分**を入れ、ブラー後に角度から種類を復元して**パレットの正確な色**で塗る。追加パス・追加テクスチャなし。
- ③ 密度: 空いたチャンネル (b) に**圧縮した生密度**を入れ、染色の深さと核の帯に使う。色相は動かさない。
- ② 異種の粒子 (i): 近づいた別種類の粒子は、壁の外の**独立した小さな点**として見せる。壁を押し出さず、細胞質に色を混ぜない。
- 実装順: ① -> ③ -> ② (①で空くチャンネルを③が使い、②は①のあとに見直す)。各フェーズは単独で動く状態でコミットする。

## 共通: scope の field の中身 (①で変わる)

scope のときだけ、field / shaped / small / large のチャンネルの意味を次のようにする (glass / cell は従来の rgb = 色のまま)。

| 場所 | r | g | b | a |
|---|---|---|---|---|
| field (splat 出力) | `w cosθ_t` | `w sinθ_t` | 0 | `w` |
| shaped (small 用、shape 出力) | `c cosθ̄` | `c sinθ̄` | `d` (圧縮密度、③。`c` を掛けない) | `c` |
| shaped large (soft、shape 出力) | `c_soft cosθ̄` | `c_soft sinθ̄` | 0 | `c_soft` |

- `θ_t = 2π (t + 0.5) / N`、`t` = 粒子の種類 (min(t, 15))、`N` = `palette.numTypes` (1〜16)。`N` は OrganicParams の新フィールド `numTypes` (f32 でよい) で渡す。
- 平均の埋め込み `e = rg / max(a, EPS)` (shape では `f.rg / max(f.a, EPS)`)。純粋な 1 種類なら `|e| = 1`、隣り合う 2 種の中点で `cos(π/N)`、離れた 2 種の中点では小さくなる。`purity R = |e|`。
- 復元: `u = atan2(e.y, e.x) / (2π/N) - 0.5` (連続な種類座標、種類 t で整数)、種類 `s = round(u)` (mod N)。
- 負の値が入るので、field / shaped / ブラー用テクスチャは符号つきの浮動小数 (rgba16float のまま)。mobile の RGBA16F も同じ。bspline など補間は負値でも線形なので問題ない。念のため mobile で負値がクランプされないことを確認すること。
- 角度の境界の AA は `fwidth(u)` を使わない (atan2 の折り返しで跳ぶ)。`gw = (length(dFdx(e)) + length(dFdy(e))) / max(|e|, 0.1) / (2π/N)` を u 単位の 1 px 幅とする。

### 種類ごとの染色色は CPU で作る

- 現在 composite の画素ごとに呼んでいる `stainColor` / `stainTransmit` (OKLab 変換) は、**パレットが変わったときだけ JS で計算**して uniform の配列に入れる (`stain[16]` = 密度 1 の染色の色、`transmit[16]` = `min(stain / SCOPE_BG, 1)`)。WGSL / GLSL の `stainColor` と OKLab 関数は削除する (どこからも呼ばれなくなる)。
- JS 版は `src/palette.js` か新規 `src/stainColor.js` に置く。現行 WGSL と同じ式・定数 (`STAIN_DL` 0.15、`STAIN_CHROMA` 1.2、`STAIN_CMAX` 0.19、黄の下げ幅 smoothstep(0.74, 0.9)、範囲外は線形 RGB で同じ L の灰色へ寄せる、最後に clamp(0.03, 1)) を使う。node のテストで「全 N (1〜16) で結果が 0.03〜1 に収まる」「パレットの色相 (OKLab の a, b の向き) が保たれる」「N = 3 / 6 / 10 の種類間の最小 ΔE x100 が仕様書の値 (29 / 14 / 5) に近い」を確認する。
- `SCOPE_BG` は WGSL の値 `(0.93, 0.94, 0.88)` と JS で共有する (定数を 1 か所にして、WGSL へは文字列で埋め込むか uniform で渡す)。

## フェーズ 1: ① 種類の描き分け

1. splat の頂点シェーダ: scope のときは `out.color = vec3f(cosθ_t, sinθ_t, 0)` (PC は `O.style == STYLE_SCOPE`、mobile は uniform の分岐かスタイル別のプログラム)。
2. shape (small 用 `shapeField` の occupancy、soft 用 `softField`): scope のときは上の表のとおり、`meanColor(f)` の代わりに `f.rg / max(f.a, EPS)` を使い `(e * c, 0 (③まで), c)` を出す。glass / cell は従来どおり。
3. composite (`scopeStyle`) の色の使い方:
   - 小器官: `e_s = s.rg / max(s.a, EPS)`、`u_s`、`s_s = round(u_s)`。色は `stain[s_s]` / `transmit[s_s]`。種類の境界は `weight = saturate((0.5 - |u_s - s_s|) / max(gw, 1e-4) + 0.5)` ではなく、**隣の種類との切り替え**として AA する: `u_s` の小数部 `f = u_s - floor(u_s)` に対し `mix(transmit[floor(u_s)], transmit[floor(u_s)+1], saturate((f - 0.5) / gw + 0.5))` (mod N)。N = 1 のときは常に `transmit[0]`。
   - 混合域: purity `R = |e_s|` が低い所 (離れた種類の混合・ほぼ同量の混合) は、染色の彩度を `R` に応じて落とす: `chromaKeep = smoothstep(0.35, 0.75, R)`、染色色を同じ輝度の灰色へ `(1 - chromaKeep)` だけ寄せる (定数 `SCOPE_PURITY_LO/HI`)。第三の種類が偽って現れるのを避けるための安全弁。
   - 区切り線: 小器官の内側で、種類が切り替わる位置 (`|f - 0.5|` が小さい所、幅 ~`0.8 dpr` px、`gw` で換算) に細い暗線を引く (色 = 両側の `outline` 色の平均を暗くしたもの、不透明度 ~0.5)。接する小器官が別の物に読めること (dots の描き分け)。
   - 細胞質 (体): `e_l = l.rg / max(l.a, EPS)` から同様に復元し、`transmit` は**隣の種類との線形補間** (切り替えの幅を u 単位 0.5 にしたソフトな版。広い領域で硬い境界を出さない)。
4. 設定・GUI に新しい項目は足さない (既存の `scopeStain` / `scopeVignette` / `scopeSpeck` / `threshold` / `blurLarge` のまま)。
5. mobile (`organicGl.js`): `SPLAT_VS` / `SHAPE_OCC_FS` / `SOFT_DOWN_FS` / `SCOPE_FS` を同じ変更に。`uStain[]` / `uTransmit[]` を uniform 配列で渡す (16 本、パレット変更時だけ更新)。

実装メモ (フェーズ 1、PC 版。仕様からの変更点):

- 切り替えの AA は `(f - 0.5) / gw` ではなく、e 空間で境界の半直線までの符号付き距離 `side = dot(e, (-sin φ, cos φ))` (φ = `(floor(u) + 1) 2π/N`) を `|dpdx e| + |dpdy e|` で割った px 距離を使う。隣の種類同士では同じ値になり、N = 2 や対蹠の種類 (e が原点を通り f が 0.5 を通らない) でも AA と区切り線が効く。
- 安全弁の範囲は R の固定値 (0.35, 0.75) ではなく N で正規化した値 (上限付き。`organic-rendering-spec.md` の scope の節)。固定値だと N = 2 / 3 の正しい境界が弁にかかり、N = 10 / 16 では偽の種類を消せない。
- 小器官の安全弁は彩度を落とす (灰色へ寄せる) のではなく、不透明度 `cover` を `keep` 倍にする (隙間をぼかしが埋めた所を隙間として見せる)。灰色の版は光沢のある白い楔に見えた。細胞質だけは明るい灰色へ寄せる。 **(後で変更: 下の「混合域の両側」。cover は周りが純粋な小器官で占められていれば落とさない)**
- 細胞質の補間の幅は `saturate(side / sin(π/N) + 0.5)` (|e| = 1 で u の幅 0.5 にほぼ等しい)。
- `stain[]` は uniform に入れているが composite は `transmit[]` だけ読む。
- mobile (`organicGl.js`) も同じ式・定数で移植済み (`uTransmit[16]` + `uNumTypes`。`stain[]` は渡さない)。field が負値を持つが RGBA16F・線形補間・3 次 B スプライン (重みが非負) で問題なし。

受け入れ (フェーズ 1):

- 2 種類の粒子の塊が接する所で、境界に第三の色相が出ない (パレットの色だけ)。
- N = 1, 2, 3, 6, 10, 16 で破綻しない (N = 1 は従来どおり単色)。
- glass / cell / dots の出力が変更前とピクセル単位で同じ (固定 seed のスクリーンショットを比較)。
- WebGPU の validation エラーなし。`OrganicParams` のフィールド追加は `ORGANIC_FIELDS` と WGSL の struct を一致させる (`assertOrganicLayout`)。

## フェーズ 2: ③ 密度で色を変える

1. shape (small 用): `b = d`、`d = 1 - exp(-(v / SCOPE_DENS_S)^SCOPE_DENS_P)`、`v = f.a * O.fieldGain`。初期値 `S = 12, P = 1` (実測表: 殻 v 2〜5 -> d 0.15〜0.34、大細胞 p90 v 10 -> 0.56、300 粒以上の塊 v 27〜42 -> 0.89〜0.97)。`c` は掛けない (輪郭 `m` とは独立)。ブラーはそのまま線形に平均する。mobile の `SHAPE_OCC_FS` も同じ。
2. composite: `ρ = s.b` (small ぼかし後の圧縮密度)。
   - **(PC 実装で変更: 下の実装メモ (フェーズ 2) を参照。指数には `min(dens, 1)` だけを掛け、濃くする分は `luma(T)` のスカラーの累乗。下の式のままだと橙が赤に寄る)**
   - 染色の深さ: 現在の指数 `k * m * thick * grain` を `k * m * thick * grain * (SCOPE_DENS_BASE + SCOPE_DENS_GAIN * ρ)` に (初期値 BASE 0.6、GAIN 1.4)。薄い縁は淡く、濃い芯は深い。色相は `pow(T, 指数)` なので保たれる (色そのものを累乗しない)。
   - 核の帯: 現在の「`n >= 0.85` で最大 20% 暗く」(核小体) は廃止し、`ρ` で置き換える: 芯 (`smoothstep(0.6, 0.95, ρ)`) で最大 ~30% 暗く、わずかに染色の彩度を上げる (**色相は変えない**: 暗くするのは `pow(T, 追加の指数)` で)。細胞の核のように中心が濃く見えること。
   - 輪郭の線の色 (`outline`) は ρ が高いほど濃く。
3. 定数 (`SCOPE_DENS_S/P/BASE/GAIN`) は WGSL / GLSL で同じ値。見た目で調整してよいが、**色相を変えない**ことと、薄い縁が従来より濃くならないこと (ρ 小で BASE が効く) を守る。

実装メモ (フェーズ 2、PC 版。仕様からの変更点):

- **染色の指数に `(BASE + GAIN ρ)` をそのまま掛けると色相が動く**。`pow(T, x)` は x > 1 で吸収の強い成分ほど速く落ちるので、橙の染色 (OKLab h58、x = 1) は x = 1.5 で h44、x = 2 で h37 (赤)、紫 h295 は x = 2 で h280 になる。そのため指数には `min(dens, 1)` だけを掛け (薄い所を淡くする方向だけ)、1 を超えた分と核の帯は**透過率の輝度のスカラーの累乗** `lt^x` (`lt = luma(T)`) で暗くする (スカラー倍は OKLab の L と C を同じ比で縮めるので色相は動かない。吸収の強い種類ほど暗くなり、黄はあまり暗くならない)。
- 小さな密な塊 (20〜30 粒) も small の ρ が 0.45〜0.6 に達し、大細胞の芯 (0.75〜0.85) と ρ だけでは分けられない。濃くする項 (`deep` と核の帯) には `big = smoothstep(0.3, 0.5, n)` (large の n。旧核小体と同じく大きな細胞の目安) を掛ける。
- 彩度の上げ幅は 0.1 (sRGB のまま灰色から離す。0.3 で橙が 6° 赤へ寄った)。
- 輪郭の線は `pow(T, 2.2 k)` の指数を上げず (すでに x > 1 で、上げるほど赤へ寄る)、同じ `lt^(k deep)` を掛ける。
- 暗くする処理はすべて `body` (と `outline`) に入れ、`mix(col, body, cover)` の前に置く。フェーズ 1 の不透明度のフェード・区切り線はそのまま効く。
- 式 (定数は WGSL の `SCOPE_DENS_*` / `SCOPE_DEEP` / `SCOPE_CORE*`。mobile も同じ値):
  - shape (small 用、scope のときだけ): `b = 1 - exp(-max(v, 0) / 12)`。
  - composite: `ρ = s.b`、`dens = 0.6 + 1.4 ρ`、`big = smoothstep(0.3, 0.5, n)`、`core = smoothstep(0.55, 0.8, ρ) * big`、`deep = 0.35 * max(dens - 1, 0) * big`、`lt = luma(T)`、
    `body = col * pow(T, k m thick grain * min(dens, 1))`、`body *= pow(lt, k (deep + 0.6 core))`、`body = max(mix(luma(body), body, 1 + 0.1 core), 0)`、そのあと従来のレリーフ・スペキュラ。`outline = col * pow(T, 2.2 k) * 0.6 * pow(lt, k deep)`。旧核小体 (`n >= 0.85` で 20% 暗く) は削除。
- 実測 (既定のシーン、N = 6): ぼかし後の ρ は殻・縁 0.2〜0.4、小さな赤い塊 0.45〜0.6 (n ≦ 0.3)、大細胞の芯 0.75〜0.85 (n 0.5〜0.8)。芯の OKLab L は 25〜33% 下がり (橙 0.60 -> 0.46、緑 0.55 -> 0.37、紫 0.52 -> 0.43)、色相の中央値はパレットの染色の色相 ±3° で変更前と同じ。小さな塊は変化なし (縁がわずかに淡い)。暗くした橙は茶色っぽく見える (彩度 C/L は保たれるが、暗い橙は茶に読める)。

受け入れ (フェーズ 2): 大きな細胞の芯が縁より明確に濃く、核のように見える。縁・小さな塊の見た目は従来から大きく変わらない。種類の色相は芯でも保たれる (橙が赤に寄らない)。

## フェーズ 3: ② 異種の粒子を独立した点として見せる

目標: 純粋に近い細胞 (A) の近くに別種類 (B) の粒子・小さな塊があるとき、(1) B が A の壁を押し出さない、(2) B が A の細胞質に色を混ぜない、(3) B が壁の外にあっても、ある程度の塊なら**自分の輪郭を持つ独立した点**として描かれる。
複数の種類でできた 1 つの生物 (核が A、殻が B など) を壁で割らないこと。「多数派だけを体とみなす」方式は使わない。基準は「周りの同種の質量」。

1. 前フレームの large ぼかしを shape の入力に束縛する (現在のフレームでは shape のあとに書かれるので、読み書きの衝突はない。最初のフレームは 0 で、減衰が無効になるだけ)。
2. shape の soft (large 用) 整形で、テクセルの種類座標 `u_p` (自分の `f.rg / f.a` から) と、同じ位置の前フレームの large `l_prev` から `D = round(u_D)`、`R_l = |e_D|`:
   - `foreign = smoothstep(0.55, 0.85, R_l) * saturate(circDist(u_p, u_D))` (`circDist` = N を周期とする種類座標の距離。同種で 0、1 以上離れると 1)。
   - `c_soft *= 1 - scopeIsolation * foreign` (新しい設定 `scopeIsolation` 0〜1、既定 0.85、0 で従来)。純粋に近い (R_l が高い) 細胞の中・周りの異種だけが減衰する。混合した生物 (R_l が低い) は減衰しない。
3. 小器官のゲート: 通常は従来どおり `n >= 0.2 * scopeSpeck` (ごみの抑制)。**異種の塊** (小器官の種類 `s_s != D` かつ `R_l` が高い) のゲートだけは、`n` ではなく**密度** `ρ >= SCOPE_FOREIGN_RHO` (初期値 0.35 = 7 粒以上の塊) に置き換える (壁の外でも、ある程度の塊なら描かれる。1〜数粒の異種は従来どおり描かれない)。
4. 壁の外の異種の塊には、自分の輪郭 (小器官の `outline`) が付く。壁は付かない (soft 整形が減衰しているため)。
5. 細胞質の色 (体の染色) は、フェーズ 1 のとおり `l` から復元する。②で `l` が異種を除いているため、異種の色は混ざらない。
6. GUI: `scopeIsolation` を `organicStyles.js` の scope の `params` に追加、`config.js` の既定 0.85、`gui.js` に項目、`renderer.js` の `COPIED_PARAMS` / `ORGANIC_FIELDS` に追加。mobile の設定シートにも出すかは後で決める (まずは既定値を `org` に渡すだけ)。
7. この減衰はヒューリスティック。効果が足りないときの次の手 (今回は実装しない): 種類グループごとの large 場。

実装メモ (フェーズ 3、PC 版。仕様からの変更点):

- **D と純度は減衰しない場から求める**。shaped large を `(c e, c_body, c)` にし (b = 体の場 = `c_soft (1 - scopeIsolation foreign)`、rg / a は減衰しない)、composite は壁・`厚み`・`big` に `l.b`、細胞質の色と D に `l.rg / l.a` を使う。仕様どおり c_soft 全体を減衰すると、除いた分だけ次のフレームの純度が上がってさらに除く正のフィードバックになり、既定のシーンの「赤い殻 + 他の種類の小さな核」の細胞が 1/3 ほど縮んだ (双安定で、塊の大きさが変わっても戻らない)。今の形はフィードバックが無く、止めた状態ではフレーム 3 / 10 / 30 が同じ画。
- **D に囲まれたテクセルは除かない** (仕様に無い追加)。large のぼかし (σ 0.45 rMax) は小さな細胞と同じ大きさで、既定のシーンの核 (質量の 19%) と縁の侵入者 (5%) は large の |e| も |u - D| もほぼ同じ (0.75 / 0.10)。区別できるのは位置だけなので、生の field を 8 方向 x 3 距離 (スプラット半径の 1〜3 倍) 見て、D (`dot(f.rg, e_D) >= 1.5`) がある方向の割合 h で `foreign *= 1 - smoothstep(0.65, 0.9, h)`。前の候補 (`foreign > 0`) のテクセルだけで計算する。
- 純度は |e| だけでなく `|u_l - D|` でも下げる: `pure = smoothstep(0.55, 0.85, R_l) * (1 - smoothstep(0.1, 0.25, |u_l - D|))`。N = 6 で隣の種類の等量混合は R = cos 30° = 0.87 で、|e| だけでは純粋と見なされる。
- 小器官のゲートは**減衰しない l.a** で判定し (`nGate`)、異種の塊は `max(nGate, foreignS * aaStep(ρ, 0.35))` (仕様の「置き換え」ではなく max。壁の中の数粒の異種は従来どおり描く)。nGate も l.b にすると、境界ぎりぎり (l.a ≈ 0.2) の小さな細胞の小器官が消えた。`foreignS` に `smoothstep(0.03, 0.08, l.b)` を掛ける (細胞の遠い裾の中の塊は対象外)。
- 純度のしきい値を下げた版 (R 0.25〜0.5 / 0.4〜0.7) も試した: 30 粒の侵入がある細胞の壁は少し縮むが、既定のシーンで境界の細胞の壁が小器官を横切り、疎な雲がしみとして出たので採らなかった。
- 結果 (既定のシーン、固定 seed): 縁の数粒の侵入で膨らんでいた壁 (2 つの赤い細胞) が丸くなり、核は縮まない。多種類の生物 (preset 3、20000 粒) はほぼ変化なし・割れない。人工のシーン (120〜240 粒の細胞のそばに 7〜30 粒の塊): 塊が周りの質量の 1 割を超えると効かない (large のぼかしが細胞より広いため)。7〜10 粒の塊は ρ 0.30 前後で 0.35 に届かず、新たに点として描かれることはほとんどない。動かしたときの A-B-A のちらつき (画素) は 0 と 0.85 で同じ。描画時間は swiftshader で +7〜20% (全画面 1 フレーム)。実 GPU では未計測。
- mobile へ移すときに要るもの: soft-down のパス (SOFT_DOWN_FS) に前フレームの large ぼかしのテクスチャを束縛 (このフレームの large の FBO とは別のパスなので読み書きは衝突しない。作り直した直後は 0 で初期化)、生の field も (囲みの判定)、b に体の場、composite で n / 厚み / big に l.b、ゲートの l.a と ρ の max。

受け入れ (フェーズ 3):

- 固定 seed で、純粋な細胞に別種の小さな塊が近づく場面の前後を比べ、壁の輪郭の歪みが減り、塊が壁の外の独立した点として見える。
- `scopeIsolation = 0` で従来に戻る (回帰確認)。
- 多種類の 1 生物が壁で割れない。

## 追加: 混合域を両側の純粋な小器官で塗る (PC 版)

実機 (60000 粒、6 種類) の報告: 黄の核 (種類 4) を紫 (0) の小器官が囲む細胞で、黄と紫が接する所に白い隙間の線が出て、紫の輪がばらばらの塊に、黄の核に切り欠きが見えた。0 と 4 は隣でない (2 つ離れた) ので接触帯の純度が低く、フェーズ 1 の安全弁 (cover を keep 倍) が透明にしていた。フェードの幅は small ぼかしと同じなので、細い小器官ほど削られる。

実装メモ (PC 版。`organic.wgsl.js` の `pureSides` / `scopeStyle`。式・定数は `organic-rendering-spec.md` の scope の節):

- `keep < 1` かつ `m > 0.2` の画素だけ、small ぼかしを 8 方向 x 2 距離 (混合の幅 `mixPx = sqrt((0.3 r_splat)^2 + σ_small^2)` の 1 / 2 倍) 読む (16 タップ)。タップの得点 = `keep_k x smoothstep(0.2, 0.35, m_k)`。色は「e がどの純粋な候補に寄っているか」の上位 2 つ A / B の切り替え (e 空間で A と B の垂直二等分線までの距離、約 1 px の AA、区切り線つき)、不透明度は `keepEff = max(keep, smoothstep(0.15, 0.35, cov) x smoothstep(0.6, 0.95, share))`。混合した e そのものは復元しない (候補は純粋なタップの種類だけ) ので、`keep < 1` になる組 (N = 6 では 2 つ以上離れた組、N = 10 では 3 つ以上) の間に偽の中間の種類は出ない。**ただし `keep` の上限 (R 0.55 / 0.75) のため、N = 10 の 2 つ離れた組 (中点 R = cos 36° = 0.81) と N = 16 の 3 つまで離れた組 (R ≧ 0.83) は `keep = 1` (純粋扱い) で、従来の復元のまま偽の中間の種類の帯が出る (変更前と同じ。純粋な画素は従来どおりという方針のため)。N = 16 の 4 つ離れた組 (R 0.71、keep 0.88) は `smoothstep(0.75, 1, keep)` で自分の復元が半分ほど混ざり、中間の帯が淡く残る**。直すなら N が大きいとき正規化した純度 < 1 でもタップを使うが、隣の種類の接触もタップの経路に入るので今回はしない。
- `sigmaSmall` (small ぼかしの σ、field px) を OrganicParams に追加 (20 フィールド)。混合の幅はスプラットの核 ((1 - d²)³ の σ ≈ 0.3 半径) と small ぼかしの両方で決まり、どちらも GUI で変えられるので、片方の倍数では足りない。
- 試して採らなかったもの (どれも既定のシーン・乱数ルール N = 10 / 16 の実際の画で破綻した):
  - 得点の最も高いタップの種類を A、次を B とする: 候補の入れ替わりで色・不透明度が画素単位で跳び、3 種類が接する所に角ばった白い穴、多種類のガスの塊にまだらの模様が出た。-> 得点を隣り合う 2 種類に連続に分け (`w = saturate(side / sin(π/N) + 0.5)`)、種類ごとの最高点・合計を取り、A / B は e との向き (`dot(e, 種類の向き) - (1 - best)`) で選ぶ。
  - 不透明度を A の得点だけで決める: 人工のシーンの多種類のガス (平均の 3 倍の密度) が、近くの純粋な塊の色で大きく塗られた。-> タップの得点の平均 `cov` (周りが純粋な小器官で占められている割合) と、上位 3 種類の割合 `share` を掛ける。上位 2 種類にすると 3 種類が接する点に白い星形の穴が残った。
  - e が弦 AB の上にあること (2 種類だけの混合) を条件にする: 3 種類が接する所が必ず穴になり、N = 16 で弦の判定が画素単位で揺れて引っかき傷のような縁になった。不採用 (`share` で足りる)。
  - keep の途中で自分の復元と A / B を keep で混ぜる: 自分の復元が隣の偽の種類 (紫 + 黄 -> 緑) を指す所で、淡い色と区切り線の弧が出た。-> `smoothstep(0.75, 1, keep)` で戻す。
- 結果 (固定の状態で前後比較、`swiftshader`):
  - 報告の再現 (人工のシーン: 黄の核 + 紫の塊の輪 / 細い紫の輪 / 星形の核の間の紫、粒子を直接置いた): 黄と紫の間の白い隙間が消え、区切り線 (約 1 px の暗線) だけになる。細い輪 (幅 0.14 rMax) はつながる。幅 0.1 rMax の輪は混合が強く大半が黄になる (従来は丸ごと消えていた)。
  - 粒子の無い隙間: 0.12 rMax の隙間は、同じ種類どうし (紫-紫) でもぼかしで埋まる。異なる種類どうしでも同じく埋まり、区切り線で分かれる (従来は異種の場合だけ白い隙間に見えていた)。0.2 rMax の隙間は前後で同じ。
  - 既定のシーン (preset 1、N = 6): 接する小器官 (橙の核 + 紫の輪 + 黄など) の白い隙間が区切り線になる。4 種類以上が入り組んだ点には小さな白い穴が残る (柔らかい縁)。パレットの色相から 15° 以上離れた画素の割合は 6.8% -> 7.4% (塗られる面積が増えた分。25° 以上は 0.06% -> 0.09%)。
  - N = 1 / 2 / 3: 画素単位で同じ (keep < 1 の画素がほぼ無い)。N = 10 / 16: 色相の外れは同じか減少 (0.39 -> 0.35% / 0.26 -> 0.22%)。疎な多種類の生物の小器官の欠けが減るが、入り組んだ所の縁は従来よりやや不規則。
  - 偽の中間の種類 (2 つの塊を接して置いた人工のシーン): N = 6 の 0|2・0|3・0|4 は白い隙間 -> 区切り線だけ。N = 10 の 0|4 は同様に直り、0|3 は隙間 -> 淡い中間の帯 + 区切り線 2 本、0|2 は中間の帯のまま (変更なし)。N = 16 の 0|2 / 0|3 / 0|4 は中間の帯のまま (前後ほぼ同じ)。上の上限のため。
  - 30000 粒の縮尺 (σ_small ≈ 0.9 field px) でも人工のシーンの隙間は閉じ、輪はつながる。
  - 確認は止めた画だけ。粒子が動くときに、3 種類以上が接する点の画素ごとの選択がちらつくかは未確認。
  - ガスの塊 (多種類): ほぼ従来どおり透ける。純粋な塊の縁に淡い縁取りが少し増える。
  - glass / cell / dots は画素単位で同じ。
- 費用: タップを読む画素は既定のシーンで全画素の 3%、N = 16 で 5.5%。その画素で bilinear 16 回 + 復元 16 回 + N の候補ループ。全体の平均では 1 画素あたり 1 回未満の追加読み出し (GPU では分岐の不揃いで、接触帯を含むワープはその分を払う)。実 GPU では未計測。
- mobile (`organicGl.js`) は未移植。移すときは同じ式・定数で、`uSigmaSmall` (field px) を渡す。mobile の small は 3 次 B スプライン (`bspline()`、bilinear 4 回) で読んでいるが、タップは純度と種類を見るだけで微分を取らないので、**タップは bilinear 1 回の `texture()` でよい** (16 回)。それでも重いときは 4 方向 (±x, ±y) x 2 距離 (8 回) か 8 方向 x 1 距離 (8 回) にする (人工のシーンの接触帯は 1 距離でも埋まる見込みだが未確認)。GLSL ES ではタップの分岐は `keep < 1.0 && m > 0.2` の if で囲んでよい (中で dFdx / fwidth を使わない)。`best[16]` / `sum[16]` の配列は動的な添字の書き込みになるので、GLSL ES 3.0 では問題ないが、遅いときは N ≦ 16 のループを候補 4 つの固定長の表 (種類, 得点) に置き換える。
